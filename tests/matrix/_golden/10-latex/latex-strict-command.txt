 latex-strict-command
 `.bib` 字段里遇到*未定义 LaTeX 命令*时的行为。
 期望 true（缺省）：严格——渲染期报错，便于及早发现拼写错 / 漏写的命令。 false：宽松——静默丢弃该命令、保留其后
 内容、继续渲染。 典型的未定义命令：拼写错的 \foobar、\noopsort{zzz} 一类 bst 时代的排序代理、 以及 CJK 紧贴吞掉命
 令名的 \textbf 中文（词法器把 \textbf 中文 整体当成一个命令名）。 与 latex-strict-char 各自独立。verbatim 字段（url /
 doi / eprint）不做 LaTeX 转换、不受影响。 仅全局生效（没有逐表 / 逐次覆盖）。                                                ⚠️   true 遇到未定义命令就报错停编译，
 没法与 false 的宽松渲染并置于同一文档—— 报错那档在 contract/panic/ 验证。


▸ true（缺省）· 命令定义良好 → 照常渲染
