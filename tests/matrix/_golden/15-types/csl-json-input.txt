 CSL JSON 输入
 除 biblatex `.bib` 外,`bibliography()` 也收 CSL JSON（顶层 `[` / `{` 自动识别）。CSL JSON 经 `src/parse/csl-json.typ` 适配器转
 成与 citegeist 同构的 entry dict,再走同一套渲染层——`.bib` 与 JSON 输出一致。名字数组、date-parts 在 Typst 层直接构造
 `parsed_names` / `parsed_dates`,不经 citegeist WASM。
 期望 CSL JSON 各能力映射到 GB 著录:
 • 类型:article-journal→[J]、book→[M]、chapter→[M]// 析出、webpage→[EB/OL];有 DOI/URL 的期刊出 [J/OL]。
 • 名字:family/given 直接搬,non-dropping-particle→前缀(van der),literal→机构 / 整体名(中国科学院)。
 • 日期:issued.date-parts → 出版年;circa: true → 估计年置「[]」;只有 literal(非 EDTF)时原样著录(1705（康熙四十四年）
   ——biblatex date 承受自由文本)。
 • 富文本:<i>→斜体、<span class="nocase"> 保护大小写;字面 & / _ 等特殊字符按字面著录(不被 LaTeX 词法器误伤)。
 • 容器:container-title 按类型分派——期刊入 journaltitle、析出入 booktitle(母体)。
 • 地图:type: map→[CM],scale→题名后比例尺、dimensions→出版年后尺寸(2025 §8.13);标准 biblatex 无这两个字段,CSL
   JSON 却有,经此注入。
 • 预印本推断:CSL 里预印本是 type: article + publisher=平台(arXiv…)+ pubstate: prepublished,无专门类型。据此还原成
   预印本 → [PP/OL]. 平台(创建日期)[引用日期]。预印本平台 id(number,article 类型本会映成 eid)不当引文页码著录——§8.15.2
   平台式无引文页码槽。
