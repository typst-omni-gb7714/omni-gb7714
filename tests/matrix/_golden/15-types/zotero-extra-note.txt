 note/Extra 字段
 Zotero 把没有 BibTeX 字段的 CSL 变量塞进 `note`（vanilla `.bib` 导出）或 CSL JSON 的 `note` 变量,每行 `变量: 值`。`src/
 parse/csl-extra.typ` 扫 `note`/`annotation`,复用 `csl-map` 词表把*已知* CSL 变量注入对应槽位——`.bib` 与 JSON 同处生效。解
 析对齐 Zotero `extractExtraFields`:标签小写+空格→连字符归一、仅已知变量提取、同名文本后者胜、同名名字累加。
 期望 note 里的 CSL 变量被抽出注入,余文留作 note 正文:
 • 已知变量注入:page→页码、Original Date→出版年回退、issued→出版年、edition→版本、author（多行）→累加成
   多个责任者。
 • 地图 scale / dimensions:标准 biblatex 无这两个字段（Zotero 只能塞 note）,现按胡振震 biblatex-gb7714-2025 的同名字段注
   入,驱动渲染在题名后（比例尺）与出版年后（尺寸,2025 §8.13）。
 • 地图类型推断:@misc 带了地图专用字段 scale / dimensions（字段形式，或 note 里的标记注入后）→ 判为 map 出 [CM]。
   这两个字段只对地图有意义,vanilla 导出遇 biblatex 无 map 时退成 @misc 却带着它们,据此还原;只补 misc 这个兜底桶。
 • tex.entrytype 显式覆写:导出也可能把真类型记进 note 的 tex.entrytype: <类型>,检测到就覆盖 entry_type（优先于推断，
   要求 tex. 前缀）。
 • tex.* 透传剥离:BBT 把 biblatex 专有信息追加成 note 末尾的 tex.<字段>: <值>。omni 不渲染,一律剥掉——否则 biber 折行后
   会被前一个已识别变量的值吞进去、漏进正文。
 • tex.* 字段名含下划线:.bib 里的 \_ 进 citegeist 前先变私用区哨兵（渲染末端才还原为 _）,不在 [a-z0-9_] 内;字段名匹配
   连哨兵一起吃、再还原成 _——否则 tex.author\_transliteration\_en 等透传字段漏过,剩在 note 里被 Number: 行的值一路
   吞进 eid 渲染出来（实测 b.4:11）。
 • 文章编号 vs 期号:CSL number（文章编号）在文章类映到 eid（→按页码著录，§7.7）、issue（期号）另存,两者分槽不再互
   相覆盖。
 • 标准类型推断:vanilla 导出遇 biblatex 无 @standard 时退成 @misc（type / genre 常丢，只剩 number）。靠 genre（→type 含
  「标准」/「standard」）或 number 的标准编号强特征还原 → [S]（编号前置）。misc 本不渲染 number,误判至多著录一个否
   则丢弃的编号,无下行风险。
 • 已注册 PID 注入:CSTR（国标特有、非 CSL 标准变量）与用户经 custom-pids 注册的自定义 PID（URN 等）也从 note 抽
   出、注入对应 PID 字段,走 PID 管道著录在 URL 之后;否则整行漏成 note 正文渲染在错位（页码后 URL 前）。DOI / ISBN /
   ISSN 早由 csl-map 词表认出。
 • 专利 jurisdiction / holder:CSL jurisdiction（专利国别）仅专利类型映到 location（§8.10 专利国别取 location，别的类
   型不动）;tex.holder（BBT 逃生舱，CSL 无 holder 变量）→ holder 名字角色（建 parsed_names，否则专利责任者错落到
   发明人）。其余 tex.<字段> 同理注入对应 biblatex 字段。
 • BBT 透传消费与显式字段胜:tex.<字段> 逐个消费、注入对应字段（名字角色建 parsed_names，其余作文本），真实字段在
   就跳过（holder 真字段与 note 里 tex.holder 并存时用真字段、不重复）;tex.entrytype 仍作类型覆盖。
 • 显式字段胜:真实 biblatex 字段 / 已有责任者优先,note 只填缺失（date={2020} 压住 note 的 issued: 1900）。
 • .bib 换行折叠:biber 把 note 换行折成空格,本 pass 按已知标签边界再切;折叠行里最后一个值后跟的自由备注会被并进该值
  （biber 所致,JSON 因保留换行不受影响）。
 • 地图作析出文献:Book Title（→container-title→地图的 booktitle）在场时,地图（[CM]）走析出驱动,得「析出题名.
   比例尺[CM]
 • 裸 DOI 不吞进 pages:Zotero「Extra」把裸 DOI（10.xxxx/…，无 DOI: 标签）单列一行,biber 折行后紧跟在前一个值（如
   Pages: 35）后成 Pages: 35 10.1002/…,DOI 被吞进页码。_split-line 认出裸 DOI 模式作独立边界切断前值,但随后丢弃、
   不回收成 doi——GB §5.1:3 与李泽平 / 胡振震都不著录它,回收会把 [M] 变 [M/OL] 并多出 DOI。故 pages 干净收「35」。
 • 认全 CSL 变量、杜绝泄漏:csl-map 认全套 CSL 1.0.2 变量名。omni 无渲染槽的（original-author / original-title /
   medium / abstract 等）判为 drop——构成边界、消费丢弃。这样折叠成一行的 Pages: 798 original-author: … original-
   title: … 里，Pages 的值在 original-author: 处断开、不再贪婪吞并后续字段漏进版面（实测 b.1:12：…2010:798 干净收
   尾，不再拖出「original-author: …」）。真·自由备注（非 CSL 变量）仍留 note 正文。
