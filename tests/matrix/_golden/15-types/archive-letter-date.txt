  档案 / 书信（[A]）日期 × 版本
  `@archive` / `@letter` 的 `date`（形成日期）如何著录，随版本切换。
  期望 档案类（标识码 [A]）的 date 是形成日期，与出版年不同。著录形态版本相关：
  • 2025：§8.12 例 [2]「武汉: 湖北省档案馆, 1931-11-07」、例 [4]「[A/OL]. 1570-07-28」——保存者后 / 标题后接全日期（YYYY-
    MM-DD），平铺、不加圆括号。有保存者（institution / location）走专著式出版项、 日期取全日期；无保存者的书信走电
    子资源支，形成日期平铺（不进创建 / 修改日期的圆括号）。
  • 2015：无「保存者, 全日期平铺」格式。附录示例中脱机 [A]「…广西师范大学出版社, 2001」只出出版年； 联机 [A/OL]
   「(2005-07-12)[2011-07-12]」的形成日期进圆括号、后随引用日期。故本包 2015 版档案走专著式出 出版年、书信走电子资
    源支的圆括号式——即历史行为。
  • 2005：无 [A] 码，档案 / 书信一律归其他 [Z]（见 _omni-mark-override），走电子资源支，形成日期进圆括号。

  门控按 entry_type 精确判档案族（archive / letter / legislation）+ version == 2025，不用宽泛的 mark == "A"：@manual
  也判 [A]，但李泽平 .bst 把它当 [M] 图书、§8.12 无 manual 示例，故 @manual 仍出年、 不随档案全日期；@legislation 两家
  引擎（胡振震 typetarget=archive、李泽平 FUNCTION{legislation}{archive}） 都归 archive，故与 archive/letter 同族出全
  日期。2015 与 2025 不同是标准版本差异；2005 无 [A] 码天然不触发。
