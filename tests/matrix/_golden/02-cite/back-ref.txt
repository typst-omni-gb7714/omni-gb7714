 back-ref
 文献表条目末尾是否回链到正文引用处（反向引用）          。
 期望 true：条目编号变成链接，点击跳回正文首次引用处；没被引用过的条目编号仍是纯文本。false（缺省）：编号纯文
 本。 编号先裹 box 再交给 link：宿主常见的 show link: it => { h(..); it; h(..) }（补回 text run 末尾丢掉的 tracking）
 会把间距插到编号前面，全角 ［ 不再是行首第一个字符、Typst 的行首开括号挤压失效，被引用的 条目编号比未引用的右
 移半个字宽（实测 12pt 下 6.2pt，编号甚至被挤到下一行）。裹了盒子后间距落在盒外， 最后一例里被引用的 ［1］ 与未引
 用的 ［2］ 必须同列对齐、同在一行。


▸ false（缺省）

正文：[1-2]
[1] 张三，李四，王五，等. 中文专著示例：副标题[M]. 3 版. 北京：示例出版社，2020：12-25.
[2] Smith J，Doe J，Roe R，et al. English Book Example[M]. 2nd ed. New York：Example Press，2021：30-45.

▸ true

正文：[1-2]
[1] 张三，李四，王五，等. 中文专著示例：副标题[M]. 3 版. 北京：示例出版社，2020：12-25.
[2] Smith J，Doe J，Roe R，et al. English Book Example[M]. 2nd ed. New York：Example Press，2021：30-45.

▸ true + fullwidth-bracket + 宿主 show link 补间距：被引用 ［1］ 与未引用 ［2］ 编号同列不错位

正文：[1]
［1］ Zhang San. Alpha[M]. X：P，2020.
［2］ Li Si. Beta[M]. X：P，2021.
