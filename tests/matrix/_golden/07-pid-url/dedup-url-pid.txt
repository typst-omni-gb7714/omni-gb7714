  dedup-url-pid
  标识符已被 URL 承载时，是否不重复著录（GB/T 7714—2025 §7.9.1）。
  期望 true（= auto 缺省）：精确值匹配——著录出来的获取路径（URL）里含该标识符的字面值时抑制它 （https://doi.
  org/10.1234/abc 含 10.1234/abc → DOI 不重复）   。只按值匹配，不按类型标记（曾用「URL 含 doi.org/ 就压 DOI」，会把指
  向另一资源的 DOI/arXiv 误压，已删）。 eprint 用剥掉体系标签后的裸 id 比对：PSSXiv:202408.01096 著录时剥成
  202408.01096，url .../abs/202408.01096 含裸 id → 抑制该 eprint（§7.9.1 的 PID 指裸 id，不含 PSSXiv: 标签）；CSTR / DOI
  无标签，按原值比。 false：关闭去重，标识符不论 URL 内容一律独立输出。 show-pid 里显式置 true 的标识符总是强制显
  示，本参数只影响 auto 状态者。
