  dedup-url-pid
  标识符已被 URL 承载时，是否不重复著录（GB/T 7714—2025 允许）。
  期望 true（= auto 缺省）：双重检测，命中任一即抑制该标识符—— ①值匹配：URL 子串含该标识符的字面值（https://
  doi.org/10.1234/abc 含 10.1234/abc）； ②类型标记匹配（小写）：URL 含该标识符的形态特征（doi.org/、cstr.cn/、
  arxiv.org/、isbn:、issn:； 自定义标识符按 <prefix 或 bib-field>: 派生）。 false：关闭去重，标识符不论 URL 内容一
  律独立输出。 show-pid 里显式置 true 的标识符总是强制显示，本参数只影响 auto 状态者。 语料 pid-all 的 URL 正是
  https://doi.org/10.1234/example——值与类型标记双双命中。
