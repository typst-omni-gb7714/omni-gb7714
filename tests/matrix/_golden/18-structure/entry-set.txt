 @set 条目集
把几条文献合并成*一个*编号 / 一个标签。
期望 @set{main, entryset = {a, b}}：a 与 b 在文献表里合并成一条（一个编号、一个骨架， 成员逐条著录在其下），正
文引用 main 得一个标注。 引用成员键（@a）会重定向到集主条目——标签与编号都是集的。 著者-出版年制的标签：用条目
里显式的 label 字段作整体标签；没有 label 字段就退化成 key （对齐 biblatex v3.8+ 静态条目集的默认解法——集不是一个
人写的一篇文献，没有天然的「著者-年」）。 脚注制下集的完整著录 = 各成员依次著录。 成员条目不再单独出现在文献表里
（full: true 也不会）。


▸ 顺序编码制：集合并成一条

正文：[1-2]
[1] 张三. 条目集成员甲[M]. 北京：社，2018.
     李四. 条目集成员乙[M]. 北京：社，2017.
[2] 丁. 题名里有半角逗号, 分号; 问号? 叹号![M]. 北京：社，2020.

▸ 引用成员键 → 重定向到集

正文：[1]
[1] 张三. 条目集成员甲[M]. 北京：社，2018.
     李四. 条目集成员乙[M]. 北京：社，2017.

▸ 著者-出版年制 · 无 label 字段 → 标签退化成 key

正文：（set-main）
张三，2018. 条目集成员甲[M]. 北京：社.
  李四，2017. 条目集成员乙[M]. 北京：社.

▸ 著者-出版年制 · 有 label 字段 → 用它作整体标签

正文：（王五, 等, 2019）
王五，2019. 条目集成员丙[M]. 北京：社.
